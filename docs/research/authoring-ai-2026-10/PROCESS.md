# Research process: authoring experience and AI (2026-10-25)

How this research was run, so future sessions can see how the conclusions were reached.

**Why:** Shawn (the client, an older non-technical chef who writes over several days) is the only author.
Before building the AI features in ROADMAP §2 (quiet assistant) and §4 (AI Mode), Jacob asked for directed
research: what has been done before, what is new in our approach, best practices, and what other authors
found hard and what helped.

**How:** one research agent, run in phases. After each phase the organizer (Claude, main session) reviewed the
output and wrote feedback, which the agent used for the next phase. Web content was treated as untrusted data;
the agent could only write its phase file.

| Step | File | Who |
|---|---|---|
| Phase 1: landscape scan | `phase-1-landscape.md` | Research agent |
| Review 1 | `review-1.md` | Organizer |
| Phase 2: deep dives on the gaps | `phase-2-deep-dives.md` | Research agent |
| Review 2 | `review-2.md` | Organizer |
| Phase 3: WordPress implementation guidance | `phase-3-implementation.md` | Research agent |
| Review 3 | `review-3.md` | Organizer |
| Final report | `REPORT.md` | Organizer |

Start with `REPORT.md`; the phase files hold the detail and sources.
